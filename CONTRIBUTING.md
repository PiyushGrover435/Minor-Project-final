# Contributing

Thank you for contributing to Sentin-Edge AI.

## Development Setup

1. Create and activate a virtual environment.
2. Install dependencies from requirements.txt.
3. Run the app with python main.py.

## Pull Request Guidelines

1. Keep pull requests focused and small when possible.
2. Include a clear summary of what changed and why.
3. Update README.md when behavior, setup, or usage changes.
4. Ensure no generated, local, or secret files are committed.

## Code Style

1. Prefer readable, modular Python.
2. Add comments only where logic is not obvious.
3. Preserve privacy-first behavior (no frame persistence by default).

## Reporting Issues

When opening an issue, include:

1. Operating system and Python version.
2. Steps to reproduce.
3. Expected vs actual behavior.
4. Relevant logs and traceback details.
